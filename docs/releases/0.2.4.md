# Fractal 0.2.4

Fractal 0.2.4 makes the AI connection work on macOS and Linux, and fixes the in-app CLI installer on every platform.

- **Codex and Claude detection on macOS and Linux.**
  - Apps opened from Finder, the Dock or a desktop launcher get only a minimal PATH, so installed CLIs went unseen. On macOS, Claude was also looked up only under its Windows file names.
  - Fractal now reads your login shell's PATH at startup and also checks `~/.local/bin`, `~/.claude/local`, Homebrew, npm, nvm, Volta, Bun and pnpm locations. An npm-installed Codex also finds Node.
- **In-app installation.**
  - **macOS and Linux:** Claude installs with the official `install.sh`. Codex installs with `brew install --cask codex` on macOS, otherwise with `npm install -g @openai/codex`.
  - **Windows:** fixes the Codex npm install, which failed on argument quoting. Also fixes the Claude install when Fractal was started from PowerShell 7.
  - A failed install now shows the installer's own last message.
  - The setup screen shows install commands for the Hub's operating system.
- **Verified in CI.** A new workflow installs both CLIs with Fractal's installer on Linux, macOS and Windows, then detects them from a desktop-launch PATH.
