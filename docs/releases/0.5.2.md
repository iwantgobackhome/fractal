# News Papers 0.5.2

News Papers 0.5.2 keeps textbook figure grids whole.

- **Figure grids.** A caption whose bold label ("Figure 3.18") is set apart from its text by a wide space no longer splits the figure: every panel stays in one crop on the translated page, and the caption is one block. PDFs already in the library are re-extracted when opened; finished translations are kept, and only changed captions are translated again.
