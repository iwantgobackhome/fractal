# Fractal 0.2.3

Fractal 0.2.3 fixes Android highlights that 0.2.2 saved but did not show, and adds update notices on macOS.

- **Android highlights and notes.**
  - In 0.2.2, a selection that started or ended inside a word was saved with a text range that every reader rejected, so the highlight or note stayed hidden on the phone and the desktop.
  - New selections no longer save that range.
  - Highlights and notes already saved this way are repaired the next time you open their page on Android, and the repair syncs to the desktop.
- **macOS update notices.**
  - The Mac apps are unsigned, so they cannot install updates themselves.
  - From 0.2.3 they check the latest GitHub release at startup and every six hours, then show **Open download page** for a newer version. Install that DMG over the existing app.
  - Installs of 0.2.2 or earlier need this one manual install first.
