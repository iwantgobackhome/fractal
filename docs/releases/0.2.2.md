# Fractal 0.2.2

Fractal 0.2.2 fixes Android reading, pen and sync problems reported on 0.2.1, and a desktop popup bug.

- **Android text selection.**
  - A long press then drag now selects by character, even on PDFs whose text the Hub could only read line by line.
  - Selection follows the visual line, so inline math such as "N = 6" no longer jumps into the line above.
  - Tapping anywhere else on the page clears the selection.
- **Android answer markers.** Minimizing an answer leaves a small marker in the page margin (**?** for questions, **i** for explanations) next to the selected line. Tap it to reopen the answer. Markers stay after you ask something else and after the app restarts.
- **Android pen settings.**
  - The fine width slider moves again and shows the current size.
  - Hovering the stylus over a tool, or long-pressing it, shows the tool name.
- **Android sync.**
  - Papers added on the desktop now open in the reader on the phone instead of showing "metadata only".
  - When the library can't reach the Hub, it shows the actual error under the message.
- **Desktop.** The model list in the answer popup no longer closes on its own while a translation is running.
