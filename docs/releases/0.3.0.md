# News Papers 0.3.0

Fractal is now **News Papers**. This release renames the apps and the GitHub repository, adds a new N·P icon, and shows the app version in Settings.

- **New name and identity.**
  - The desktop app, installers, Android app, menus and docs are now called News Papers. The repository moved to `iwantgobackhome/news-papers`; old links redirect.
  - Desktop: on first start, News Papers copies your Fractal library, history, annotations and settings to its new data folder. The original folder is left untouched.
  - Android: News Papers is a new app (`app.newspapers.reader`), so it installs next to Fractal. Pair it with the desktop again: your library, ink and history sync back from the Hub. Then you can remove Fractal.
  - Fractal 0.2.x apps are offered this update. Android receives it through a transitional `Fractal-0.3.0-android-debug.apk`, an identical copy of the News Papers APK.
- **New icon.**
  - The app icon is a new N·P monogram on stacked pages, generated from one source for macOS, Windows, Linux and Android.
  - The macOS Dock icon now follows the macOS icon grid. The menu-bar icon is a small monochrome template that adapts to light and dark menu bars.
- **Settings → About / version** shows the running version and a **Check for updates** button.
