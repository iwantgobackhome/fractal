# Fractal 0.2.1

Fractal 0.2.1 adds in-app updates, makes desktop-to-mobile pairing more reliable, and reworks reading and annotating on desktop and Android.

- **In-app updates (Windows, Linux, Android).**
  - On packaged Windows NSIS and Linux AppImage/deb builds, Fractal checks this GitHub release feed. It offers **Update** or **Later**, then **Restart to update**.
  - On Android, Fractal checks the latest release, verifies the APK against `SHA256SUMS.txt`, then opens the system installer.
  - macOS stays DMG-only and has no updater.
  - 0.2.0 has no updater, so install 0.2.1 by hand once. Later versions are offered from inside the app.
- **Pairing and sync.**
  - Android sync uploads are split into small batches. The Hub now accepts sync batches up to 4 MiB, so large ink histories no longer fail with "request body too large".
  - Pairing-code attempts are rate-limited separately from failed device tokens.
  - Pairing reports Hub errors and missing LAN/Tailscale addresses clearly.
- **Answer popups.** Questions and figure/equation explanations open in a floating popup next to the selection, on both desktop and Android. You can drag, collapse and close it, and ask follow-up questions in it. Answers are still saved to history.
- **Android input.**
  - The text-selection mode is gone: a finger swipe scrolls, a long press then drag selects text, and the pen always writes ink.
  - Selection follows characters within the dragged column instead of grabbing whole blocks.
  - The eraser shows a circle at its true radius and erases as it moves.
- **Regions and highlights.**
  - While you drag a region, a live rectangle shows the area (the toolbar **Region** button on Android).
  - Detected figures, tables and equations on Android get an **Explain** chip.
  - Tap or click a highlight to delete it.
