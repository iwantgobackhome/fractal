# News Papers 0.4.0

News Papers 0.4.0 improves translated papers and reworks questions.

## Translation

- **Figures.** Diagrams drawn as vector graphics (boxes, arrows and their labels) are kept as one figure. Their labels are no longer translated as body text.
- **Paragraphs and titles.** A bold abstract stays one paragraph instead of breaking at every line. A title that spans two lines is one heading.
- **Symbols.** Accented letters and math accents (ŷ, X̂, é) are kept intact.
- **Inline math.** Math inside a sentence stays in the sentence. Only displayed equations are shown as images.
- **Exported PDFs.** In side-by-side and translation-only exports, each original page fits on one sheet. A translated page that is too long continues on a sheet marked "continued".
- **Android translations.** The translated view now shows figures, tables and equations from the original page, in reading order. A page label appears once per page, not above every paragraph.

Opening a paper extracted by an earlier version extracts it again. Existing translations are kept for every paragraph whose text did not change. Paragraphs whose text changed, such as a rejoined abstract, need translating again.

## Questions

- **Conversations.** Questions and answers build up as a conversation. Follow-up questions include the earlier turns of the same conversation. Sending a question clears the input. Editing the input, changing the model or removing a quote no longer hides earlier answers. **New question** starts a new conversation, and earlier conversations are listed under History.
- **Quotes.** Selected text is attached above the input as a quote for the next question only. Removing it with × removes only the attachment. After sending, the quote is shown with that question.
- **Simpler input.** The question input has only a model picker and a send button. The answer language, including a custom language tag, is set in Settings.
- **Resizable panel.** On the desktop, drag the left edge of the side panel to resize it. The width is remembered.

These changes apply to both the desktop and Android apps.
