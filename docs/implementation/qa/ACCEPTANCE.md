## Interaction and state checklist

- [ ] Mouse/trackpad scroll, keyboard navigation, finger pan/pinch/long-press, physical pen draw/erase/selection are separate verified paths.
- [ ] Pending/loading/success/empty/error/cancelled/retry/offline/stale states have deterministic output and no indefinite spinner.
- [ ] General question and explanation history retain quote, page, model, answer and status after close/reopen, process restart and device recreation.
- [ ] Draft/selection reset rules are intentional; paper switching drops old in-flight results and never attaches old context to new paper.
- [ ] Notes/memos preserve body and optional quote separately; region-only note remains useful on scanned/older-API PDF.
- [ ] Recent versus Saved, folders/multiple membership/tags and last-viewed ordering survive sync and migration from old library records.
- [ ] Settings language/theme/provider choice survive reload; rapid edits and Hub write failure do not silently revert on next load.
- [ ] Pull/push interleaving does not advance past unconsumed remote seq; dirty local edits, remote deletion and retry/restart do not skip or resurrect data.
- [ ] Offline cached PDF/translation/notes are readable; uncached PDF has actionable state; network return merges without duplicating entries.
- [ ] Long PDF/mixed page sizes/two columns/equations/figures/scanned pages and partially translated papers exercise actual geometry and selection.
- [ ] Menus/dialogs/bottom sheets close by Escape/back/outside click as appropriate, preserve focus and never swallow document gestures.
- [ ] Screen reader names, focus order, keyboard-only paths, larger font and high DPI are checked on representative surfaces.

## Required hardware and integration evidence still outstanding

1. Physical Galaxy Tab + S Pen: model/OS/API/build SHA, orientation/window mode/density, pen/palm/button behavior, slow/fast strokes, pen-up/down page anchor, cancelled input, screen recording and measured transform. Injected mouse/touch/stylus or emulator events cannot satisfy this gate.
2. API29–34 physical/emulator text-selection fallback and API35 native text selection: exact quote, range extension, handles/copy/memo/ask. Emulator can satisfy software-path evidence, not pen hardware behavior.
3. Android install/launcher icon, adaptive mask, UI rendering, rotation/recreation, split-screen/DeX, keyboard and accessibility on a disposable app profile paired to a temporary Hub. Do not attach user's paired app or real library.
4. Packaged Electron installer/executable/tray/shortcut/taskbar/DPI and native close-to-tray/relaunch history on isolated FRACTAL_DATA and user-data directory. Browser-only checks cannot satisfy native shell gates.
5. Controlled Hub/device concurrency run for history, note/saved/folder sync and cursor interleaving; then E independently rechecks integrated A/B/C/D changes at a recorded SHA. Use selected meaningful existing tests and narrowly scoped regression cases once owners authorize implementations/tests; do not create a broad suite that only repeats code structure.
