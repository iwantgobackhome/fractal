## Decisions

- Kept the existing `%LOCALAPPDATA%\PaperRead` and XDG data paths, `PAPERREAD_DATA` override, `x-paperread-token` header, local storage keys, and existing user-facing UI copy for compatibility. Only package names and the page title changed to Fractal.
- Kept the hub on loopback and used `GET /api/papers` as the readiness/list check because PaperRead has no separate health route.
- Vite fetches the hub-injected page token during development and proxies `/api`, allowing existing authenticated browser writes without changing the API.
- Added `woff` and `ttf` asset MIME types so KaTeX fonts emitted by the workspace build load from the hub.
- Kept the full PaperRead MIT license. (Upstream screenshots were dropped at merge time because the UI will be replaced.) The old standalone usage guide was omitted because its source paths and build commands became stale after the move.

## PaperRead behavior not preserved

No intentional runtime behavior was removed. Live arXiv acquisition and Codex account, translation, and question flows were not exercised in this check; the build, pure-logic tests, hub API, and static assets were verified. `npm ci` reported two moderate dependency advisories.
