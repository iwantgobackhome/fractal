# W2-E: Paper structure recognition

## Summary

Added versioned PDF structure extraction for captioned figures and tables, display equations, numbered and author-year bibliography entries, and tappable numeric citation markers. The PDF.js detector reuses extracted blocks and checks PDF text geometry and math fonts. arXiv source archives can enrich matching items with LaTeX and labels. Reference details use cached, lazy Semantic Scholar lookup with OpenAlex fallback. Detection starts after blocks are saved and remains available through a refresh route.

The fixture PDF and tarball under `packages/hub/test/fixtures/` are generated by `generate.py`; they are original test material, so no third-party PDF license is needed. The three arXiv PDFs used below were downloaded only for the manual run and are not committed.

## Endpoints

| Endpoint | Result |
| --- | --- |
| `GET /api/papers/:key/structure` | Version, status, items, references, markers; HTTP 202 while running |
| `POST /api/papers/:key/structure/refresh` | Starts a background pass; HTTP 202 |
| `GET /api/papers/:key/references/:n` | Entry and cached or newly fetched enrichment |
| `POST /api/papers/:key/references/:n/add` | Ingested paper through existing URL/DOI/arXiv flow |

## Decisions

- Structure version `pdfjs-structure-v1` invalidates older records on read. SQLite migration 5 adds state, item, reference, marker, source, and enrichment tables. It is gated on version 5 alone so it can follow main's citation and feed migrations 3 and 4.
- Caption-only graphic fallbacks receive confidence `0.38`; they approximate the crop when PDF.js finds the caption but misses the graphic region.
- Equation detection combines the existing PDF.js fragment crops with a second pass over centered, symbol-dense/math-font rows. Numeric ranges are expanded only when bounded to 50 numbers.
- arXiv source fetch is limited to 20 MB and 12 seconds; only `.tex` regular tar members are read into memory. PDF-only or unavailable source returns PDF-only structure. Source fragments are cached per paper revision.
- Reference enrichment is requested only on detail/add, paced at 500 ms between outbound requests, and cached by DOI, arXiv ID, title, or raw entry. `SEMANTIC_SCHOLAR_API_KEY` is optional.
- `StructureDetector` is the integration seam for Docling. A future adapter can invoke `C:\Users\Home\anaconda3\envs\fractal\python.exe` with bounded input/output and normalize its boxes; no Python package was added.

## Known gaps and integration notes

- PDF layouts vary. The Vision Transformer PDF yielded three fewer figure boxes than caption numbers, while the diffusion paper yielded six fewer detected display equations than numbered right-margin anchors. Caption-only boxes should be reviewed before using them as exact crops.
- The Vision Transformer paper uses author-year in-text citations. Its bibliography is parsed, but author-year markers are not linked; numeric markers and ranges are linked.
- Author-year reference boundaries are best effort, especially where PDF extraction merges adjacent entries. Enrichment may return `null` when neither upstream provider has a match.
- The UI can consume `items`, `references`, and `markers` directly from the structure endpoint and poll while status is `running`; no UI changes were made in this worktree.
